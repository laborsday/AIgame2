# 《免疫防线》

动作肉鸽（Action Roguelite）· 2D 俯视角 · Python + Pygame

## 剧情

一名确诊肝癌的大学生，在手术麻醉的梦境中，以「纳米意识」潜入自己体内，指挥白细胞对抗癌细胞……梦境里的胜负，决定现实里他能否醒来。

## 运行

```bash
pip install pygame           # 或 pygame-ce（推荐，本项目用 pygame-ce 2.5.8 验证）
pip install flask            # 可选：本地「档案管理」面板（自动随游戏启动；不装也能玩）
cd immunedefense
python main.py
```

启动后浏览器打开 **http://127.0.0.1:8765** 查看档案管理面板（或在主菜单左下角点击地址小字）。
数据（存档/战绩/成就/祭点流水）保存在本机 `%LOCALAPPDATA%\Immunedefense\immunedefense.db`
（受限环境自动回退「游戏目录 data/userdata」，均不进版本库）。

## 操作

| 键 / 鼠标 | 功能 |
|---|---|
| WASD / 方向键 | 移动（纯走位躲弹幕，无闪避技能） |
| 鼠标左键 | 标定目标/地面（指挥白细胞） |
| 点击底部细胞卡 / 1-4 键 | 召唤对应白细胞（1 中性 / 2 巨噬 / 3 T / 4 NK，常驻，场上 ≤ 上限） |
| 按住 Q | 打开书包（使用 / 穿戴 / 丢弃道具，松开关闭） |
| E | 档案室：靠近家具互动；清房后：靠近商店台打开商店 |
| Tab | 图鉴（遇敌解锁能力说明） |
| ESC | 结尾时退出 |

## 玩法

- **指挥官 + 军队**：玩家脆皮跑得快、不直接攻击，靠「标定 + 身位」双轨引导 4 种白细胞——中性粒细胞（冲脸咬/迟钝多细胞核）、巨噬细胞（坦克嘲讽+减伤）、T 细胞（远程+识别伪装）、NK 细胞（标定瞬间 AoE 爆发）。
- **8 房 3 层递进**：初始教学房 + 7 间战斗房；肝脏表面（崩溃）→ 肝脏深层（挣扎）→ 肿瘤核心（和解）；每房清完三选一（得卡/强化/道具）；**层间沿血管洞口向下**，同层走房间门；**已清过的房可随时返回**（快照还原，不重刷怪）；每间房布局来自房间模板池（坏死细胞堆 + 半 3D 血管障碍），都有碰撞体积。
- **敌人**：癌细胞（睡眠态静止、每 5s 分层增殖，外观与攻击态无区别）、变异伪装（T 细胞标记前无法集火）、狂暴/护盾/召唤三种精英、癌变核心 BOSS（三阶段：分裂变异体 → 加速分裂 + 精英残片 → 螺旋弹幕 + 场地毒区）。
- **v3 道具层**：按住 Q 打开 7 格书包（**格 0 = 留念格：重开保留道具**，拖动可交换位置；每格叠 6）；预防针（攻 ×1.3 / 15s）、止痛药（受伤 −50% / 10s）、红细胞、医药费、妈妈的炖汤；**装备**——奶奶的针织衣（减伤 6 / 耐久 12）、手术刀（三刀环绕 4 伤 / 耐久 36），穿脱即时生效、破损有文案。
- **v4 祭点层 · 祭坛**：白细胞死亡按其击杀数累计**祭点**（牺牲的记忆）；主菜单 / 死亡结算 / 通关结算三入口打开「祭坛 · 记忆之匣」——**记忆类** 13 项（通用 ×5 + 类型记忆 ×8，Ⅱ 档需先学 Ⅰ 档 + 首次击败 BOSS 解锁，下一局生效即淡忘）；**实物类** 1 件——**左半钥匙**（200 祭点，或普通/精英房 1% 掉落），兑换后下一局开局放入背包。
- **v4 双半钥匙**：右半钥匙 = **BOSS 清房 100% 掉落**（自动入包，占格；固定格可跨局攒）；双半自动合成**完整的钥匙**（开局注入时也检查合成）→ 档案室侧门第二次打开：按 E 消耗完整钥匙 → **档案室·左半（暮色书房）** —— 读纸 → 触发 **TE2 真结局线**（占位演出）。
- **v4 档案室重开**：首次进入免费（66% 侧门 → 阳光书房四选一照旧）；离开后侧门**不再封死**，变为上锁的门（四态：live/visited/opened）；开门条件 = 完整钥匙（左半+右半）。BOSS 清房后**不立即结算**：必掉右半钥匙 + 房间中央生成**告别之门**（走进才结算 NE/TE），返回口开放——两条路线：打完就走（NE）或回头开档案室（TE2）。
- **肉鸽循环**：死亡 → 2s 手术室闪回 → 结算 → **祭坛**兑换 → 重开（固定格道具跨局保留）。
- **v5 数据库系统**：存档/战绩/成就/**祭点流水**全部写入本机 **SQLite**（`systems/dblocal.py` 单一数据层；`systems/meta.py` 底层切换、旧 json 档首启自动迁移）；成就「战友的徽章」（3 次完美局 → 每局免疫第一次致命伤）；随游戏启动的本地**档案管理面板**（Flask 只读 · 深底暖金 · 仪表盘/战绩/成就/流水四页）。
- **成长**：杀敌得 XP → 升级三选一进化；残血心跳加速（狂暴 4 档，T 细胞档 2 穿透射击 / NK 档 2+ 爆发强化）、伤害飘字、震屏、数字残留癌细胞计数（右上）。

## 打包分发（v5）

```powershell
pip install pyinstaller
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
# 产物：packaging\免疫防线-v5-win64.zip（onedir，自动校验不含开发者存档/数据库）
```

玩家拿到 zip：解压 → 双击「免疫防线.exe」即玩（内嵌数据目录自动初始化，首次为全空档）。

## 测试

```bash
pip install -r requirements-dev.txt   # pytest（仅首次）
cd immunedefense
python -m pytest -q                   # 109 个用例：玩法/战斗/敌人机制/装备/档案室/祭坛钥匙/数据库/成就/面板/叙事/萤火虫/回归
```

> 从仓库根跑 `python -m pytest immunedefense/tests -q` 亦可。
> `conftest.py` 已把 git 根注入 `sys.path`（`server/` 包所在处），任一目录都不报
> `ModuleNotFoundError: No module named 'server'`（tests/test_panel.py 依赖它）。

用例按功能分区落在 `tests/`（`test_gameplay.py` 玩法与机制、`test_ttk.py` 真实平衡锚定 `balance.json → ttk_targets`、`test_firefly.py` 萤火虫）；任一断言失败即报用例名 + 堆栈 + 非零退出码。
